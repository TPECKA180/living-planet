# Сторонние компоненты

Windows-сборка включает бинарный runtime [llama.cpp](https://github.com/ggml-org/llama.cpp) версии `b12628` с Vulkan-бэкендом. Исходный проект распространяется по лицензии MIT; копия лицензии находится в установленной папке `runtime/LICENSE-llama.cpp.txt`. В архиве runtime также сохранён `LICENSE-LLVM-OpenMP`.

Веса GGUF-модели пользователь размещает отдельно. GitHub-пакеты Living Planet не содержат модельных весов.
