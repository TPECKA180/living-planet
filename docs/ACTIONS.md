# Все действия нейросети

Справочник сформирован из реального реестра движка. Всего 55 типов. Каждый приказ имеет `type` и `args`. До12 приказов в основном ответе; `count` не равен количеству слотов. `cell=[x,y]`, координаты целые и начинаются с0. Все проверки и стоимость применяет движок.

## build

Построить здание на собственной клетке. Первая эпоха: 200 денег (160 с engineering) и20 сырья за уровень (15 с masonry), уровни1–10. lab требует science, mine — mountain/resource; вода, радиация и занятое здание запрещены. Современные здания используют собственные cost и ограничения каталога.

| Аргумент | Обязателен | Тип / ограничение |
| --- | --- | --- |
| building | да | {"type":"string"} |
| cell | да | {"type":"array","items":{"type":"integer"},"minItems":2,"maxItems":2} |
| level | да | {"type":"integer","minimum":1,"maximum":10} |

## unit

Создать scout/builder/army или ship. Суша: 60 денег (45 с conscription) +3 металла×сила, сила1–10, выше5 требует army. Своя свободная безопасная клетка. Для ship нужна navigation и вода рядом со своим сухим берегом. count=N — платная атомарная группа с отдельными местами; вся группа отклоняется, если средств/клеток не хватает.

| unit | да | {"type":"string"} |
| cell | да | {"type":"array","items":{"type":"integer"},"minItems":2,"maxItems":2} |
| strength | да | {"type":"integer","minimum":1,"maximum":10} |
| count | нет | {"type":"integer","minimum":1} |

## Обработка отказа

Отказ записывается в `previous_outcome.action_results` с `success=false` и причиной. Успех проверяется по состоянию и квитанциям, а не тексту `thinking`. Простые ошибочные приказы проверяются до списаний; группа найма проверяется целиком. В наборе разных приказов предыдущие успешные действия не откатываются из-за следующего отказа. Повторный день не должен повторно применять уже сохранённое общее исполнение.
