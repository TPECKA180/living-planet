# Подключение и первый запуск

## Что устанавливается отдельно

Нужны Python 3.12, библиотека pygame 2.6.1 из `requirements.txt`, LM Studio и выбранная текстовая модель. У игры нет собственного облачного сервиса, аккаунта, платного API или обязательной подписки. Скорость и вместимость контекста определяет машина, на которой работает модель. Удалённый совместимый сервер также можно указать явно; игровые данные тогда отправляются на него.

## Windows

1. Установите Python 3.12 с официального [python.org](https://www.python.org/downloads/). Скрипт установки использует Windows launcher `py -3.12`.
2. Скачайте архив репозитория, распакуйте в обычную доступную для записи папку. Не запускайте игру прямо из ZIP.
3. Запустите `install.bat`. Он создаёт локальную `.venv` и устанавливает зависимость, не заменяя системный Python.
4. Запустите `run.bat`. Если окружение ещё не создано, он пробует установленный Python 3.12; рекомендуемый путь — сначала `install.bat`.
5. При первом запуске появляется меню миров. Игра создаёт чистый локальный `config.json`, а папка `saves` наполняется только вашими новыми мирами.

## Ручной запуск / Linux

```bash
python3.12 -m venv .venv
source .venv/bin/activate
python -m pip install -r requirements.txt
python main.py
```

В Windows при ручном запуске используйте `.venv\Scripts\python.exe main.py`. Команда `python main.py --check` проверяет доступ к списку моделей, не запускает симуляцию и не проверяет качество их ответов. `python main.py --screenshot preview.png` рисует новый демонстрационный мир без запроса к модели; это не загрузка сохранения.

## Сервер LM Studio

1. Установите [LM Studio](https://lmstudio.ai/) и скачайте текстовую instruct/chat-модель, которая умеет возвращать JSON и работать с русским языком. Конкретная марка не обязательна.
2. В разделе **Developer** включите сервер. Стандартный адрес сервера — `http://localhost:1234`; игре нужен базовый адрес совместимого API **`http://localhost:1234/v1`**.
3. В игре откройте **LM Studio** из меню миров либо **F2** в самом мире. Введите адрес, при необходимости API-ключ, затем нажмите **Обновить список**.
4. Кликните поле общей модели и выберите точный ID из списка. Общая модель используется, когда у конкретного государства не задано переопределение. Модель менеджера в стандартном локальном режиме не вызывается.
5. Задайте окно, максимум ответа и целевой вход. Начальные настройки 7.5.2: окно 131072, ответ до 16384, входные факты 56000. Это цели, а не гарантия, что модель и видеопамять их поддерживают. Для небольшого оборудования уменьшайте окно; если ядро решений перестало помещаться, нужна модель/настройка с большим реальным контекстом.
6. Сохраните настройки, создайте мир и выполните один день. Сначала убедитесь, что страны получают решения и появляются реальные результаты приказов, затем включайте наблюдение.

LM Studio позволяет включать сервер через Developer; совместимый API использует `/v1`, а отдельный нативный API `/api/v1/*` предоставляет список, загрузку и выгрузку моделей. Эти методы нужны строгой изоляции игры. См. официальные [сервер](https://lmstudio.ai/docs/developer/core/server), [совместимые endpoints](https://lmstudio.ai/docs/developer/openai-compat), [список моделей](https://lmstudio.ai/docs/developer/rest/list) и [загрузка модели](https://lmstudio.ai/docs/developer/rest/load).

## Авторизация

Если сервер требует Bearer-токен, введите его в скрытое поле **API-ключ**. Он хранится только в локальном `config.json`; это поле не является шифрованием файла. Файл игнорируется Git, а экспорт настроек мира исключает `api_key`. Не вписывайте настоящий ключ в `config.example.json`, README, issue или публичный скриншот. В обычном локальном режиме LM Studio авторизация может быть выключена; при её включении запросы должны содержать токен. Официальная [инструкция авторизации](https://lmstudio.ai/docs/developer/rest/quickstart).

## Другой компьютер и другие серверы

`localhost` всегда означает компьютер, где запущена игра. Для модели на другом компьютере используйте его собственный адрес и порт с `/v1`. В LM Studio для этого есть **Serve on Local Network**; без сетевой доступности адрес не заработает. При сетевом размещении авторизация особенно уместна: см. [официальное описание](https://lmstudio.ai/docs/developer/core/server/serve-on-network).

OpenAI-совместимость чата не означает наличие LM Studio `/api/v1/models/load` и `/unload`. Для такого сервера выключите **строгую изоляцию** и **управление окном на сервере**. Игра продолжит передавать отдельные сообщения конкретного государства, но уже не сможет проверить выгрузку серверного экземпляра между странами. Не обещайте себе ту же гарантию изоляции. Сервер должен поддерживать `/models` и `/chat/completions`, обычный JSON либо SSE; JSON-схема желательна, при несовместимости есть текстовый контракт и проверка ответа.

## Создание первого мира

В меню укажите название,2–6 государств, целочисленный seed и режим. **Обычный** создаёт сушу/моря с берегами, **Архипелаг** — шесть крупных разделённых островов со стартом на разных островах. Одинаковые seed/размер/режим дают воспроизводимую географию. Нажатие «Создать» не загружает и не переносит чьё-либо сохранение. Наблюдение начинается только после соответствующей команды пользователя.
