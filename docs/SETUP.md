# Установка Living Planet 8.5.0

[На главную](../README.md) · [Справка по игре](GAME_GUIDE.md) · [Загрузить SETUPGAME.exe](https://github.com/TPECKA180/living-planet/releases/tag/v8.5.0)

## Установка на Windows

1. Скачайте `SETUPGAME.exe` из корня проекта или со страницы релиза 8.5.0.
2. Запустите установщик, выберите папку на странице **Папка установки** и при желании отметьте создание ярлыка **Living Planet** на рабочем столе.
3. В папке игры создайте или откройте `models` и скопируйте туда файл модели формата `.gguf`.
4. Запустите **Living Planet** и выберите модель в окне **Модели · F2**.

Установщик уже включает игровой интерфейс, встроенный движок llama.cpp и фирменную иконку. Python, LM Studio, API-ключ и запущенный сервер не нужны. Вес модели пользователь добавляет отдельно: файлы занимают несколько гигабайт, поэтому GitHub-сборка их не содержит.

## Переносимый архив

Скачайте `LivingPlanet-8.5.0-Portable.zip`, распакуйте в папку с правом записи и запустите `LivingPlanet/LivingPlanet.exe`. Рядом с приложением уже есть папка `models` — добавьте туда `.gguf`.

## Выбор модели и скорость

Кнопка **Модели · F2** показывает GGUF-файлы из папки `models`. Выберите нужную модель, настройте размер контекста и число слоёв, загружаемых на видеокарту, затем сохраните. Значение `99` автоматически распределяет как можно больше слоёв на GPU; `0` запускает модель только на процессоре.

После сохранения игра сама запускает локальный движок и загружает веса. При первом запуске крупная модель может загружаться некоторое время. Внизу окна показывается скорость последнего ответа в токенах в секунду; ноль означает, что движок ещё не сообщил статистику генерации.

Модель должна поддерживать GGUF и шаблон чата. Контекст и скорость зависят от выбранной модели, видеокарты, видеопамяти и оперативной памяти. Если загрузка завершилась ошибкой, проверьте `logs/local-model.log`, уменьшите окно контекста или число слоёв GPU.

## Сборка из исходников

Для разработки установите Python 3.12, зависимости из `requirements.txt`, PyInstaller и Pillow. На Windows запустите `python tools/build_windows.py`; скрипт получает официальный Windows Vulkan runtime llama.cpp и собирает переносимую папку. Положите веса в `models` до локальной сборки, если хотите включить модель в локальный пакет. Git игнорирует `.gguf`, и публичная автоматическая сборка не включает веса.

Игра не отправляет сохранения и тексты запросов на удалённый сервер. Выбранная локальная модель отвечает через `127.0.0.1`; локальный процесс завершается вместе с окном игры.
