# Вход, ответ и реальный контекст7.5.3

Целевой вход56000 токенов; верхний предел ответа196608; запрошенное общее окно262144. Это разные значения: окно вмещает системные правила, вход, ответ и технический запас. При достаточной памяти используется весь остаток окна до предела ответа. Модель может закончить намного раньше.

В7.5.3 удалены скрытые ограничения ответа до трети окна и до32768 при повторе. Настройки разрешают ответ больше половины окна. При первой миграции меньшие старые лимиты поднимаются до новых; большие сохраняются. Последующие ручные изменения не сбрасываются.

Фактическое окно подтверждает сервер. При отказе по памяти игра уменьшает только рабочий размер, показывает его и запрошенный предел в консоли и не переписывает config.json. Если сервер выделил мало памяти, одновременно получить вход56000 и ответ112000+ невозможно. Игра сохраняет данные текущих действий раньше большого резерва ответа. Квантизация кэша и отключение защиты памяти автоматически не включаются.

При stream=true запрашивается usage, чтобы учитывать реальные prompt_tokens и калибровать оценку размера. Если совместимый сервер не поддерживает stream_options, игра повторяет запрос без этого поля. Завершённый JSON не применяется дважды.

Если ответ обрезан, неполный JSON не выполняется: резерв увеличивается только в пределах окна и настроек либо запрашивается более компактный полный JSON с тем же входным бюджетом.

О загрузке и подтверждении окна: [официальная документация LM Studio](https://lmstudio.ai/docs/developer/rest/load).
