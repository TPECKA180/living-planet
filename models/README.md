# Локальные модели

Поместите совместимый файл модели формата `.gguf` в эту папку. Игра показывает найденные файлы в окне **Модели · F2** и запускает встроенный llama.cpp из `runtime`.

Вес модели не входит в GitHub-сборки и игнорируется Git. Это личный локальный файл; его можно добавить в переносимую локальную сборку.
